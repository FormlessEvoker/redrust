# redrust

An implementation of a Redis clone following the book "Build Your Own Redis" (print and online at https://build-your-own.org/redis/).

This project is a personal learning exercise to implement the ideas from the book in Rust — to force a deeper understanding of the systems concepts rather than simply translating examples. The primary learning goals are low-level TCP socket programming, building an event loop, and implementing a simple key-value cache.

## Documentation

- Foundations (conceptual): foundational networking and OS concepts, diagrams, and tutorials are available in `docs/foundations/`. See the Documentation Index: [docs/README.md](docs/README.md).
- Implementation (project-specific): design notes, API docs, and implementation rationale live in `docs/implementation/` (stub to start): [docs/implementation/README.md](docs/implementation/README.md).

## About tooling

I used GitHub Copilot as a learning and research aid during development — for explaining core concepts, understanding code snippets, comparing C/C++ examples to Rust equivalents, scaffolding unit tests, and outlining documentation. Some code and tests in this repository may have been assisted or initially generated by AI tools. This repository is intended primarily as a LEARNING TOOL.

When I reach a finalized working example that matches the book, I intend to reimplement the project by hand and replace any AI-assisted content with hand-written code. Until then, treat parts of this repo as exploratory or draft.

## Usage

This repository is not intended as production-ready software. It is an educational sandbox for exploring systems programming, TCP/IP, and protocol implementation.
